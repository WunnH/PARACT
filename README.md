# PRACT Reproducibility Materials

This repository provides manuscript-aligned methodological parameters and aggregate reproducibility information for PRACT trajectory planning.

## Contents

- `method_parameters.md`: planning-space, spatial-mapping, uncertainty, candidate-generation, screening, and runtime parameters
- `candidate_runtime_summary.csv`: machine-readable aggregate candidate counts and runtime statistics

## Scope

The materials describe the aggregate planning configuration used for the NBH-STN-DBS analysis. No patient-level data, medical images, masks, coordinates, entry points, or individual trajectories are included.
